Fine-Tune Your Graphs

Rich customization options for publication-ready figures

GIFs are captured from real UI interactions using sample data.

1 Drag to Reposition

Drag title, axis labels, and legend. You can also drag bars and sample labels.
Sample labels move vertically; bars move horizontally. Use the “i” icon for targets.

2 Axis & Tick Settings

Set Y-axis min/max values and tick intervals numerically.
Adjust scale using W/H inputs or corner handles.

3 Visual Customization

Control dot size, error bars, line thickness, bar width, and group spacing.
Bar positions are draggable and can be reset / undone / redone.

4 Save & Restore Settings

Export your customizations as a JSON file.
Apply the same settings to different datasets for consistent figures across your paper.

Using Explorer

Load local CSV/TSV/Excel files, preview them, and stage selections into groups.

1 Import files or folders

Drag & drop, or use “select from local” to import files and folders.

2 Preview and select columns

Drag-select cells in the preview. Adjust column widths and decimal visibility as needed.

3 Stage to groups

Send selected ranges to groups and apply them to the main view. File content is processed in the browser.
