# Contributing to SVG Plotter

Thank you for your interest in improving SVG Plotter!

## How to Contribute

1. **Bug Reports**: If you find a bug, please open an issue describing the problem and steps to reproduce it.
2. **Feature Requests**: Have an idea for a new feature? Open an issue to discuss it!
3. **Pull Requests**:
   - Fork the repository.
   - Create a new branch for your changes.
   - Submit a pull request with a clear description of what you have changed.
